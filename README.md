## 🛡️ Featured Projects

1. **Argus Adversarial Tool for SOC**
   - Security testing tool for blue teams and SOC monitoring.
   - Simulates common threat patterns to evaluate alerting mechanisms, log visibility, and detection rules.

2. **Packet Sniffer**
   - Real-time network traffic sniffer developed using Python and Scapy.
   - Extracts source/destination IP addresses, ports, and protocol details (TCP/UDP).
   - Features a Tkinter GUI for live packet monitoring, visualization, and logging.

3. **PyWiFi Scanner**
   - Wireless network scanner built with Python to detect fake Wi-Fi networks (Evil Twin attacks).
   - Scans nearby SSIDs, compares security configurations, and flags rogue access points.

## 🚀 How to Run / View

This portfolio is built using pure, lightweight, responsive HTML5, modern CSS3, and vanilla JavaScript. No complex build step is needed.

1. **Directly in Browser**:
   Double click or open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).

2. **Using a Local Server (Optional)**:
   ```bash
   # Python
   python -m http.server 8000

   # Or using npx
   npx serve
   ```
   Then open `http://localhost:8000` in your browser.
